# 列筛选与视频预览修复

## 修复内容

- 恢复描述、域名、类型、大小、状态、保存路径的表头筛选，可组合条件；筛选结果计数和清除筛选同步更新。
- 列表类型筛选只影响显示，不再通过 `/api/set-type` 改变新资源的抓取范围。启动时明确抓取全部类型。
- 行内预览按钮直接播放；点击标题仍显示详情。切换资源、离开页面时释放播放器。
- 本地预览接口支持 Range 的跨域请求与响应头；保留抓取到的登录请求头，历史数据可补充剩余的 Referer/User-Agent。
- 微信视频的解密前缀经受保护的本地 POST 接口传入内存，服务端按照 Range 起始位置边读取边解密。移除硬编码 AVC/AAC 编码和浏览器 MediaSource 分片追加，不缓存完整视频到前端内存。密钥不写入磁盘，删除资源/清空列表时清除。
- M3U8 播放列表的分片、子列表、密钥及初始化段地址改为本地预览地址，继承原请求头。预览请求遵循下载代理配置。
- 微信脚本处理按 URL hostname 匹配，避免显式 HTTPS 端口导致域名匹配失败。

## 验证证据

- 前端 7 项测试、TypeScript 检查与生产构建通过。
- Go 全部测试、go vet 和 Windows amd64 Wails 构建通过。
- 新增整段及多种 Range 的解密测试，覆盖加密区域边界、未加密区域及密钥清理；新增跨域 Range、播放列表地址和微信显式端口测试。
- 浏览器以生产前端包和隔离测试接口验证描述/类型/状态/路径/大小筛选、组合筛选为空、清除筛选、结果计数；图片筛选期间注入新视频后资源总数增加，抓取范围保持 all。
- 普通视频与 ISAAC 前缀加密的视频测试素材均解码为 960×540，readyState=4，无媒体错误；切换资源后旧 video 元素释放。
- 截图：`design-assets/filters-fixed.png`、`design-assets/preview-fixed.png`。截图中的资源是测试数据。

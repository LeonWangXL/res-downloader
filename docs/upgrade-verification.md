# 升级修复与验证

本轮保留 Go + Wails + Vue 技术栈，修复安全、下载正确性、任务调度和配置可靠性。没有加入 m3u8 下载、直播录制、云服务或新的平台适配。

## 已修复

- 每个配置目录生成独立 CA，私钥保存在 `ca.pem`，不再内嵌共享私钥。安装状态绑定当前证书指纹；升级安装新证书时清理旧共享证书。
- 控制接口使用每次启动随机令牌，仅允许本地访问和规定方法；令牌通过 Wails binding 交给界面。预览/证书下载使用带令牌的 URL。外部更新检查不会携带令牌。
- 不再持久化系统密码；启动清理旧密码缓存。密码仅在当前进程中使用。
- 修复短响应被判成功、单连接重试拼错文件、HEAD 错误响应被当作元数据。验证分片 Content-Range 和实际字节数。
- 原子占用目标文件名，以临时文件下载，校验完成后替换目标；失败/取消清理本次文件，不删除已完成任务文件。
- 下载 Client/Transport 复用，探测、连接和响应头有超时，正文长时间无进展会结束；取消可以中止 HEAD。
- Go 后端负责队列、并发上限和重复任务检查。成功、失败、取消都会清理活动任务。
- 首页缓存容器不会随设置页切换销毁；恢复历史时将中断任务设为可重试，按真实任务 ID 更新行，修复排序/筛选后的错误行操作。
- 进度每 200ms 更新，资源缓存延迟批量保存，资源列表与持久化历史限制为 5000 条。持久化/导出仅保留必要的非登录请求头。
- 配置由后端校验，以快照读取和临时文件替换方式保存；设置页点击“提交”后保存，并显示失败原因。Host/Port 下次启动生效，当前控制地址保持稳定。
- 接管系统代理前保存原设置，关闭恢复；启动检查恢复上次异常退出的代理。检测到其他程序已经接管时不覆盖。macOS 对无法安全恢复的认证代理拒绝接管。
- 多步骤系统操作不再以“任意一步成功”判整体成功。Windows 通知代理设置改变；Linux 避免重复启动文件管理器。
- 视频号脚本读取限制大小，支持 gzip/deflate 解码，处理失败保留原响应。修复域名端口匹配和并发资源去重。
- 预览关闭取消请求、移除监听、释放对象 URL；分块预览验证实际范围与结束位置。
- 日志错误确实写出，关闭检查文件句柄；端口占用显示启动错误，单实例重复启动显示已有窗口。
- 增加回归测试、CI 与固定 Wails v2.12.0 的构建入口。

## 本地验证与构建

需要 Go（建议使用 go.mod 中的 Go 1.23.2 工具链）、Node.js 20 或更高版本，以及 Windows WebView2 Runtime。

Windows 在仓库根目录运行：

```powershell
.\scriptserify.ps1
.\scriptserify.ps1 -Build
```

也可以双击 `build.cmd`。构建产物：`build/bin/res-downloader.exe`。

独立步骤：

```powershell
cd frontend
npm ci
npm test
npm run build
cd ..
go test ./...
go vet ./...
go install github.com/wailsapp/wails/v2/cmd/wails@v2.12.0
wails build -skipbindings -s
```

如果 npm 或 Go 的默认缓存不可写，给当前终端设置可写的缓存目录；无需改动全局工具版本。本轮验证使用临时 Go/npm 缓存。

## 升级首次使用

1. 关闭旧版本后启动新程序。新证书与旧共享证书不同，需要重新安装信任证书；Windows 机器级证书迁移需要管理员权限，macOS/Linux 按界面提示授权。
2. 设置页修改后点击“提交”。Host/Port 修改后重启；原正在运行的代理地址不会提前切换。
3. 重启后历史中的中断任务可重新下载。依赖登录态的资源不持久化 Cookie/Authorization，需要重新抓取。
4. 程序没有持久化断点续传；单连接失败从头重试，支持 Range 的分片在本次任务内重试。
5. 异常退出时其他应用可能暂时仍指向本地代理。再次启动会尝试恢复；Windows/macOS/Linux 的系统操作仍应在对应实机验收。

可通过绝对路径环境变量 `RESD_CONFIG_DIR` 使用独立配置目录；Windows WebView 数据也放在该目录。默认不设置此变量，继续使用原用户配置目录。测试配置目录不能当作已安装证书的生产配置。

## 本轮验证记录

- Go 下载、安全、队列、配置、解密、HTTP/HTTPS 代理与插件回归测试通过。
- `go vet` 通过，前端测试与生产构建通过，Wails v2.12.0 Windows 可执行文件构建通过。
- Linux/macOS 核心代码交叉编译通过。CI 配置了 Linux race 检测；本机缺少 C 编译器，没有本地运行 race 检测。
- 使用独立临时配置实际启动 Windows 界面，首页加载正常，无令牌控制请求返回 401；未安装系统证书，也未开启系统代理。
- 用户通过 Esc 停止 Computer Use，因此没有完成设置页切换及界面下载的实机测试。真实平台登录态、加密媒体播放、三平台证书迁移与物理网络恢复尚未实机验收。
- 现有 Sass/Browserslist 和大前端包警告仍在，构建成功。本轮不合并依赖大版本迁移，以便问题定位与回归。
